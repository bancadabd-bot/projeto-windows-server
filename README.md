# 🚀 Projeto Windows Server 2022 - Ambiente Corporativo

Este projeto consiste na implementação de uma infraestrutura de rede simulando um ambiente corporativo utilizando Windows Server 2022.

## 🔧 Tecnologias utilizadas

- Active Directory (AD DS)
- DNS
- DHCP
- Group Policy (GPO)
- WSUS
- File Server
- IIS (Intranet)

## 📌 Funcionalidades implementadas

- Criação de domínio corporativo (ghc.local)
- Organização de usuários por setores (OUs)
- Gerenciamento de permissões e grupos
- Mapeamento de unidades de rede via GPO
- Atualizações automáticas com WSUS
- Controle de armazenamento com cotas
- Backup automatizado
- Servidor web interno (IIS)
